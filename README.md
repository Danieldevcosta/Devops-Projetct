# Atividade Prática – Git e GitHub

## Descrição

Este repositório foi criado para uma atividade prática da disciplina de DevOps, com o objetivo de aprender e utilizar os principais comandos do Git e compreender o funcionamento do versionamento de código.

## Tecnologias utilizadas

- HTML5
- Git
- GitHub

## Comandos Git praticados

| `git clone` | Clona um repositório remoto para a máquina local. |
| `git status` | Verifica o estado dos arquivos no repositório. |
| `git add` | Adiciona arquivos à área de preparação (Staging Area). |
| `git reset` | Permite retirar arquivos da Staging Area. |
| `git commit` | Registra alterações no histórico local do projeto. |
| `git push` | Envia os commits locais para o repositório remoto. |
| `git pull` | Busca e integra atualizações do repositório remoto. |

## Como executar

1. Clone o repositório para sua máquina.
2. Abra a pasta do projeto no VS Code.
3. Abra o arquivo `hello_world.html` em um navegador.

O projeto não necessita de instalação de dependências.
